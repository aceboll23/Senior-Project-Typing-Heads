\# Needs



\## User Needs:

Need to discover new board games to play

Need to track which games they own vs. want to buy

Need to see what games friends have before game night

Need to coordinate what games to bring to a session

Need honest reviews to decide if a game is worth buying

Need recommendations based on personal taste



\## System Needs:

User authentication for personalized features

Database for users, games, collections, reviews, and playgroups

External API for game data (or manual entry)

Recommendation logic based on user reviews/preferences





\# Features



\## Public (No Login):

Browse game catalog

Read game reviews

View game details (player count, playtime, complexity, etc.)

Registered Users:



\## Create/manage account

Write and edit reviews

Add games to "Owned" list

Add games to "Wishlist"

Add friends

View friends' collections

Create/join playgroups



\## Playgroups:

See combined game collection of group members

Create game night events

Members select games they'd bring

Vote or agree on what to play



\## Future/Stretch:

AI-powered game recommendations based on reviews

Links to purchase games (Amazon, local shops)

Game night scheduling/calendar integration
